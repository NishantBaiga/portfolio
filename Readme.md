# 🌐 Personal Portfolio Website

A modern, responsive personal portfolio website built to showcase my projects, skills, and experience as a developer.

## 🚀 Live Demo
👉 https://nishantbaiga.vercel.app/

---

## 📌 Features

- ⚡ Fast and responsive UI
- 🎨 Dark / Light mode support
- 🧭 Smooth section-based navigation
- 📂 Projects section with live demos & GitHub links
- 📄 One-click resume download
- 📱 Mobile-friendly design
- ✨ Smooth animations and transitions

---

## 🛠️ Tech Stack

- **Frontend:** React, TypeScript
- **Styling:** Tailwind CSS
- **Animations:** Framer Motion
- **Icons:** Lucide React
- **Deployment:** Vercel 

---

## 📁 Project Structure
src/
├─ components/
├─ data/
├─ assets/
├─ hooks/
├─ pages/
└─ App.tsx

---

---

## 📸 Projects Section

Each project card includes:
- Project image
- Description
- Tech stack tags
- GitHub repository link
- Live demo link (if available)

If a live URL is not available, a static preview image is shown.

---

## 📄 Resume

The resume can be downloaded directly from the navigation bar using a single click.

---

## ⚙️ Installation & Setup

Clone the repository:

```bash
git clone https://github.com/NishantBaiga/portfolio.git

```
npm install
